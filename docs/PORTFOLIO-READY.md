# 포트폴리오 시연과 공개 준비

## 90초 데모

`flutter run -t lib/main_demo.dart`로 실행한다. 화면에 DEMO가 보이게 촬영하고 가상 데이터임을 설명한다.

로컬 데모 설치 파일: `v_view/build/app/outputs/flutter-apk/v-view-portfolio-demo-debug.apk`. 빌드 결과물로 Git에는 포함하지 않는다. 재생성하려면 `flutter build apk --debug -t lib/main_demo.dart`를 실행한다.

| 시간 | 보여줄 화면 | 전달할 내용 |
|---|---|---|
| 0~15초 | 데모 홈 | 혼자 하는 면접 연습에서 답변과 피드백을 남기는 문제 |
| 15~35초 | 샘플 리포트·질문 펼치기 | 완료율은 실제 작성 여부, 답변별 시간·근거·측정 품질 |
| 35~50초 | 지난 연습 비교 | 동일 조건 기록을 비교하며 %와 %p를 구분. 역량 점수로 해석하지 않음 |
| 50~75초 | 샘플 질문·답변 넣기 | 한국어 샘플을 채워 수정하고 다음 질문으로 진행. 이미 작성한 내용은 보호 |
| 75~90초 | 기록·복사 | 저장 후 재열람하고 상단 복사 버튼으로 질문·답변·근거를 문서로 옮김 |

## 설명할 기술적 판단 3개

1. **비동기 상태의 수명:** 중복 제출과 종료 후 도착한 응답이 세션을 바꾸는 문제를 세대 번호·제출 상태로 제어하고 회귀 테스트로 재현했다.
2. **측정 근거의 표현:** 만든 총점 대신 답변 완료율·시간·품질을 표시했다. 측정 불가를 0점과 구분하고 비교 대상도 같은 유형·직무·회사로 제한했다.
3. **키와 인증의 경계:** 모바일에 포함되던 키를 개인 PC의 loopback 프로세스로 분리하고 외부 접속 차단·요청 제한을 적용했다. 기존 Firebase 인증 경로는 보관하며 현재 실행에는 배포·로그인이 필요 없다. 데모는 외부 요청 없이 분리해 검토자가 재현할 수 있게 했다.

구현한 사실과 본인이 직접 판단·검증한 사실은 구분해 서술한다. AI 도구 활용 범위는 숨기지 않는다.

## 실제 앱 기기 검증표

아래는 수행할 검증이며 아직 통과한 것으로 적지 않는다.

- [ ] 기기 모델·OS·앱 빌드·네트워크 조건 기록
- [ ] PC 로컬 프로세스와 실제 Android USB 연결에서 질문·평가 확인
- [ ] 한국어 음성 답변 → 인식 텍스트 확인·수정 → 제출
- [ ] 실제 AI 피드백에 해당 답변의 근거가 포함되는지 확인
- [ ] 조명·얼굴 검출 조건을 적고 시선 측정 결과 확인
- [ ] 중간 종료·뒤로 이동·앱 전환 후 답변과 시간 유지 확인
- [ ] 생성한 기록을 앱 종료·재실행 뒤 재열람
- [ ] 권한 거부·네트워크 단절·요청 제한 시 복구 안내 확인

실제 사용자를 대상으로 한 인식 정확도·면접 성적 향상·시간 절감은 측정하지 않았다.

현재는 [로컬 AI 실행](LOCAL-AI.md)을 사용한다. Flutter 요청 코드 → PC → GPT의 실제 요청 3회를 확인했으며, 클라우드 배포는 사용자 요청으로 진행하지 않는다. 실제 휴대폰 입력 검증은 별도다.

## 기록 관리와 내보내기

기록 카드의 길게 누르기는 해당 연습의 요약·상세 답변을 함께 삭제한다. 상단 전체 삭제는 고아 상세 기록도 정리한다. 삭제가 완료될 때까지 조작을 잠그고 실패하면 같은 창에서 재시도한다.
Hive의 두 box 쓰기는 하나의 원자적 트랜잭션이 아니다. 중간 실패 시 상세만 지워질 수 있으며 재시도로 남은 요약을 정리한다. 앱 강제 종료까지 포함하는 자동 복구 저널을 구현했다는 주장으로 사용하지 않는다.

리포트 상단 ‘답변 포함 리포트 복사’는 질문·의도·내 답변·시간·측정 품질·피드백 근거를 내보낸다. 실제 외부 전송이나 자동 게시 기능은 없다. [가상 내보내기 예시](verification/v-view-export-sample-2026-11-09.md)는 실제 수행 시간을 측정한 자료가 아니다.

저장 실패 시에도 생성된 답변과 피드백은 화면에 남아 복사할 수 있다. ‘저장 다시 시도’는 기존 ID와 피드백으로 디스크 쓰기만 재시도한다. 이 경로에서는 AI 요청을 반복하지 않는다. 재시도 대상은 메모리에 있으므로 저장을 끝내거나 복사하기 전에 앱을 강제 종료하면 자동 복구를 보장하지 않는다.

실제 로컬 앱에서 새 홈 → 문항별 자료 입력 → 시작 → 현재 질문만 공개 → 필요한 확인 질문 또는 다음 질문 → 저장 리포트 → 같은 질문 재연습 순서로 설명할 수 있다. 가상 자료로 촬영하고 API 사용 여부를 명시한다. PC 연결 상태는 키·잔여 사용량까지 보장하는 상태 표시가 아니다.

새 홈·지원자 정보·자소서의 [위젯 렌더링과 검증](verification/README.md)은 TEST 표시가 있다. 이전 데모 APK는 별도 진입점과 버전의 산출물이므로 최신 로컬 앱의 홈·설정 시연과 혼용하지 않는다. 본인이 정한 요구사항, 직접 검토한 코드와 AI 도구가 생성한 작업을 구분해 설명한다.
