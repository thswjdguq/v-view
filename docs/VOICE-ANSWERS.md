# 마이크 답변과 AI 평가

## 사용 흐름

1. 면접 화면의 마이크를 누르고 마이크·음성 인식 권한을 허용한다.
2. 한국어로 답변하면 인식한 텍스트가 답변 칸에 표시된다.
3. 마이크를 다시 눌러 중지한 뒤 오인식된 내용을 수정할 수 있다.
4. 이어서 말할 때는 마이크를 다시 누른다. 기존 답변 뒤에 새 인식 내용을 붙인다.
5. 다음 질문 또는 완료를 누르면 최종 인식 결과를 정리한 뒤 답변을 제출한다.
6. 제출한 답변은 꼬리질문 판단과 최종 AI 피드백 요청에 포함된다.

AI는 질문 적합성, 경험·역할·결과의 구체성, 답변 구조를 텍스트로 평가하고 개선 근거를 제시한다. 발음·억양·목소리·표정은 평가 대상이 아니다. 요청에는 질문의 평가 포인트와 답변 시간도 포함하지만 시간·길이만으로 역량 점수를 만들지 않도록 안내한다.

## 구현

- `lib/services/speech_service.dart`: 인식 상태·오류 안내, 기존 입력 보존, 부분 결과 갱신, 최종 결과 대기, 종료 후 늦은 결과 차단.
- `lib/state/interview/speech_provider.dart`: 앱 범위에서 음성 인식 인스턴스와 콜백을 유지한다.
- `lib/ui/interview/interview_screen.dart`: 항상 표시되는 마이크, 듣는 중·실패 상태, 권한 설정 이동, 인식 텍스트의 가독성, 제출 연결.
- `lib/data/remote/ai/claude_api_service.dart`: 질문·답변·의도·시간을 평가 요청에 전달하고 근거가 있는 피드백을 요청한다.
- Android: `RECORD_AUDIO`, 인터넷 권한과 `android.speech.RecognitionService` 조회 intent.
- iOS: 카메라·마이크·음성 인식 사용 설명 키. iOS 실행은 Windows 환경에서 검증하지 않았다.

## 기기 조건

기기에 한국어를 지원하는 음성 인식 서비스가 있어야 한다. 일부 서비스는 인터넷을 사용한다. 앱은 원본 오디오 파일을 별도로 저장하지 않으며, 변환된 답변 텍스트는 AI 평가에 사용한다.

OS가 침묵이나 시간 제한으로 인식을 중단하면 현재 텍스트를 유지하고 마이크를 다시 눌러 이어서 답변한다. 무제한 연속 녹취 기능으로 표현하지 않는다. [speech_to_text 원문](https://pub.dev/packages/speech_to_text)은 짧은 발화 중심의 사용과 플랫폼별 시간 제한을 설명한다.

## 검증

2026-11-03 기준 전체 테스트 82개 통과, `flutter analyze --no-pub`에서 No issues found를 확인했다. Android 실제 앱 진입점의 debug APK 빌드를 확인했다.

외부 마이크 엔진을 대체한 테스트에서 실제 SpeechService·화면·면접 상태·리포트 입력 연결을 검증한다. AI 요청은 테스트 HTTP adapter로 전송 내용을 확인하고 실제 과금 API를 호출하지 않는다.

확인 항목:

- 기존 답변 뒤에 음성 텍스트를 붙이고 부분·최종 결과를 중복하지 않는다.
- 인식 종료와 오류를 UI에 반영하고 다시 시작할 수 있다.
- 중지 요청 직후 오는 최종 결과를 기다리고 종료 이후의 늦은 결과를 무시한다.
- 마이크 시작 대기 중 중지해도 인식기가 켜진 채 남지 않는다.
- 인식 불가여도 마이크와 안내를 표시한다.
- 음성 텍스트가 꼬리질문 요청과 리포트 Q&A 입력으로 전달된다.
- 질문 의도·답변·답변 시간이 AI 요청에 들어가고 피드백의 근거를 파싱한다.

실제 사람이 휴대폰 마이크에 말했을 때의 인식 정확도와 실제 AI 응답 품질은 별도로 확인해야 한다.

Android 에뮬레이터에서 음성 인식 서비스 2개가 조회되는 것을 확인했다. 카메라가 연결된 샘플 면접의 화면 캡처가 검게 나오는 현상 때문에 이번 음성 화면의 시각 검증은 완료하지 못했다. 이 상태를 실제 기기의 음성 입력 성공으로 표현하지 않는다.

## 2026-11-05 후속 변경

면접을 밝은 배경으로 바꾸고 카메라 미리보기를 기본 숨김·선택 표시로 변경했다. 카메라·마이크를 사용하지 않는 별도 포트폴리오 데모도 추가했다. 데모 화면 확인은 실제 마이크·카메라 검증을 대체하지 않는다. 최신 자동화·Android 확인 범위는 [검증 기록](verification/README.md)을 따른다.

현재 실제 AI 모드는 로그인 없이 PC의 로컬 프로세스에 요청한다. OpenAI 키는 PC의 `server/.env.local`에만 설정하며 앱 `.env`는 사용하지 않는다. 기본 `main.dart`가 이 로컬 모드이며, 기존 Firebase 진입점은 `main_firebase.dart`에 보관했다. 가상 입력의 실제 GPT 질문·꼬리질문·평가 연결을 확인했지만 실제 휴대폰 음성 인식 정확도를 검증한 것은 아니다. [로컬 실행](LOCAL-AI.md), [서버 안내](../server/README.md).
