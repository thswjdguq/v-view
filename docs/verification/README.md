이 문서의 첫 절은 2026-11-03 초기 검증 기록이다. 2026-11-05 후속 개발 결과는 아래에 따로 기록한다.

## 자동화 검증

- 전체 `flutter test --no-pub --reporter expanded`: 70개 통과. 기존 45개에 회귀·위젯 테스트 25개 추가.
- 면접 상태: 중복 제출, 종료·초기화 이후의 늦은 응답, 일시정지 유지, 타이머 하한, 질문별 답변 시간.
- 면접 화면: 시간 만료·직접 종료 시 답변 보존, 음성 인식 중지 대기 중 답변 보존, 잔여 시간 유지.

- 질문 생성: 실패 안내가 로딩에 가려지지 않고 같은 입력으로 재시도.
- 리포트 화면: 신규·저장 결과 통합, 완료율·측정 품질·근거·질문별 답변과 시간, 재연습·기록 이동.
- 좁은 화면: 320×740 및 글자 1.8배에서 저장 리포트와 신규 리포트 하단 버튼 확인.

전체 수에는 기존 placeholder와 단순 조건 테스트도 포함되어 있다. 테스트 수를 기능 완성도나 커버리지 수치로 사용하지 않는다.

- 같은 유형·직무·회사인 직전 기록 비교. 정상 품질끼리만 응시율 차이를 표시하고 완료율은 %p로 표현.

- 품질 필드가 없는 과거 기록은 참고용으로 읽고 측정 불가 기록을 0%로 표시하지 않음.
- 데모 화면의 샘플 리포트와 이전 연습 비교 카드 연결 확인. 카메라 미리보기는 요청할 때만 생성하고 큰 글자·좁은 화면에서도 토글 가능.
- 실제 시연에서 찾은 데모 ProviderScope 연결 오류를 화면 이동 회귀 테스트로 재현했다. 데모의 입력·질문 상태를 명시적으로 분리해 실제 AI 중계 설정을 참조하지 않도록 수정했다.

GitHub Actions는 Flutter 테스트·분석과 서버 테스트·보안 검사 설정을 추가했다. 당시에는 커밋·푸시 전이었으며 원격 CI 성공을 확인한 기록이 아니다. 최신 실행은 GitHub Actions에서 확인한다.
Dockerfile은 추가했으나 Docker 빌드·클라우드 배포는 실행하지 않았다. 실제 Firebase 인증·과금 AI 호출·휴대폰 마이크·iOS·사용자 사용성은 미검증 상태다.

### 실제 GPT 확인과 남은 한계

과금 호출은 자동 테스트와 분리한 가상 문답 네 가지로 세 번 확인해 총 12회 요청했다. 프롬프트 보완 중 성공뿐 아니라 JSON 형식 오류·현재 질문 반복·원문 인용 오타도 관찰했다. [첫 확인](v-view-adaptive-followup-live-2026-11-17.json), [보완 후 확인](v-view-adaptive-followup-live-revised-2026-11-17.json), [마지막 확인](v-view-adaptive-followup-live-final-2026-11-17.json)을 모두 남겼다.

마지막 확인에서는 충분한 답변 종료·역할 모순 확인·정정 후 종료가 파싱됐고, 역할 누락 사례는 실제 답변과 한 글자가 다른 인용 때문에 검증에서 거부됐다. 인용 검증을 완화하거나 자동 재요청으로 숨기지 않았다. 앱에서는 안내 후 기본 질문을 진행한다. 이 자료는 소수 가상 시나리오 관찰이며 모델 정확도·압박 필요성의 완전한 판정·사용자의 면접 성과를 입증하지 않는다.

임시 저장은 입력 후 400ms·시간 5초 간격의 저장 예약과 제출·나가기 시 flush를 사용한다. 강제 종료 직전 변경, 아직 저장하지 않은 AI 결과와 원본 시선 프레임까지 모두 복구하는 저널이 아니다. 시선은 재개 후 측정 구간을 참고용으로 표시한다. 실제 휴대폰 한국어 음성 정확도·조명별 시선 품질·iOS·실사용자 사용성은 이번 검증 범위에 포함하지 않는다.
