# 학교·자격증 입력용 기본 목록

앱 안에서 검색하는 명칭 목록이다. 외부 검색 요청이나 API 키 없이 사용한다. 보유 자격·학적·현행 제도를 검증하는 서비스가 아니며, 목록에 없는 국내외 학교·민간 자격은 직접 추가할 수 있다.

- 학교: 한국대학교육협의회 제공 [전국대학및전문대학정보표준데이터](https://www.data.go.kr/data/15107736/standard.do). 기준연도 2025, 데이터 기준일 2026-03-18. 공식 다운로드의 1,995행에서 학교명 중복을 묶어 1,953개로 만들었다. 같은 이름의 캠퍼스 지역·학교 종류는 설명에 합친다. 학교·학위·인증 상태의 최신 확인 용도로 쓰지 않는다. 제공기관 출처를 표시해 이용한다.
- 자격증: 한국산업인력공단 [국가자격종목별 주무부처](https://www.data.go.kr/data/15112802/fileData.do). 파일 기준일 2023-03-16, 1,228종목. **과거·변경·폐지 명칭이 포함될 수 있다.** 증서의 실제 이름을 입력하는 보조 목록이며, 현재 시행 종목 전체나 취득 증명을 뜻하지 않는다. 제공 페이지의 이용허락범위는 제한 없음이다.
- 추가 명칭: 한국데이터산업진흥원 [자격 안내 자료](https://www.dataq.or.kr/www/dataq_brochure_2022.pdf)에 있는 SQL 개발자·SQL 전문가·데이터분석 준전문가·데이터분석 전문가 4개를 더했다. 최종 자격 명칭은 1,232개다. 약칭과 띄어쓰기 검색은 앱에서 제공하는 편의 기능이다.

공개 원본은 2026-11-18 내려받았다. JSON의 `sourceSha256`은 내려받은 원본의 해시다. 검색 순서는 정확한 명칭·약칭 일치, 접두어, 기본 정렬 순이며 일부 개발 관련 자격을 먼저 보여주는 앱의 기본 설정을 포함한다. 인기도나 사용자 성과 통계가 아니다.

다시 생성하려면 공공데이터포털에서 학교 JSON과 자격 CSV를 내려받아 저장소 루트에서 실행한다. 이 명령은 네트워크에 접속하지 않는다.

```powershell
python scripts/build-profile-catalogs.py --schools schools-original.json --certifications certificates-original.csv --retrieved-at YYYY-MM-DD
```

원본 전체의 주소·전화·담당자 항목은 앱 목록에 넣지 않고 명칭·종류·학교 지역만 사용한다. 학교 데이터는 중복 이름을 합쳤으므로 캠퍼스별 학력 구분이 필요하면 학력 상세에 직접 적는다. 새 자료를 사용했다면 기준일·건수·출처 문서도 함께 갱신한다.
